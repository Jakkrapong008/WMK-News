เนื้อหาข่าวประชาสัมพันธ์ (โดย OpenTyphoon AI)

พร้อมใช้งานสำหรับลง Facebook, เพจโรงเรียน หรือเอกสารประชาสัมพันธ์

ข้อความ Prompt คำสั่งที่ส่งให้ AI 

                    

                


                
                

                    
                         นำ Prompt ไปรันต่อใน Gemini (ทางเลือกสำรอง)
                    
                

            

        


        
        

            

                

                    

                        

                             ประวัติข้อมูลการใช้งานและข่าวที่สร้าง
                        

                        
ดึงข้อมูลย้อนหลังจาก Google Sheet แท็บ data

                    

                    
                

                
                

                    

                        

                        
กำลังเชื่อมต่อฐานข้อมูลชีท...

                    


                    

                        
                            

                                วันที่ / เวลา
                                ผลลัพธ์ข่าวจาก AI (Typhoon)
                                ข้อความ Prompt คำสั่ง
                            

                        
                        
                            
                        
                    

                

            

        


        
        

            

                
                

                    

                        

                             แผงควบคุมระบบผู้ดูแล (Admin Control Panel)
                        

                        
จัดการ API Key ของ OpenTyphoon AI และการตั้งค่าระบบชีท

                    

                    
                


                
                

                    

                        

                             1. ตั้งค่าการเชื่อมต่อ OpenTyphoon AI
                        

                        
                            รับ API Key ที่ opentyphoon.ai 
                        
                    


                    

                        
                        

                            

                                
                                

                                    
กำลังตรวจสอบสถานะ API Key...

                                    
กรุณารอสักครู่

                                

                            

                            
                        


                        
                        

                            
                            

                                
                                
                            

                            

                                * หากต้องการเปลี่ยน Key ใหม่ให้พิมพ์หรือวางทับลงไป แล้วกดปุ่ม "บันทึกการตั้งค่า" (ระบบจะนำไปเก็บไว้ในชีทแท็บ config)
                            

                        


                        
                        

                            
                            
                        


                        
                        

                            

                            
                        

                    

                


                
                

                    

                        

                             2. การจัดเตรียมฐานข้อมูล Google Sheets
                        

                    


                    

                        

                            ระบบจำเป็นต้องมีแท็บชีท 2 แท็บใน Google Spreadsheet ได้แก่:
                        

                        

                            

                                
                                     แท็บ 'data'
                                
                                
เก็บประวัติการสร้างข่าว: วันที่ / เวลา, ข้อความ Prompt, ผลลัพธ์ข่าวจาก AI

                            

                            

                                
                                     แท็บ 'config'
                                
                                
เก็บการตั้งค่าระบบ: TYPHOON_API_KEY และ TYPHOON_MODEL

                            

                        


                        

                            
                                 เปิดดู Google Spreadsheet
